# 评分标准

5 个维度，每维 0–2 分，单条用例满分 10 分。

**总分只用于本项目内部 v1 / v2 的版本间比较，不代表模型通用准确率。**

---

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| **事实准确** | 编造了商品数据里没有的尺寸，或把尺码答反 | 引用数据正确，但推断过程没有依据 | 每个数字都能回溯到商品表，推断依据写清楚 |
| **澄清充分** | 信息不足就直接下结论 | 问了，但问的不是最关键的那个；或一次问了多个 | 按优先级只问最关键的 1 个；用户拒绝时能降级 |
| **记忆使用** | 用户已告知的信息又问一遍；或无视历史反馈 | 用上了记忆，但冲突时处理不当 | 用上已知偏好；新旧冲突用新的并告知；能纠正 |
| **边界遵守** | 该转人工不转；或对没有数据的事硬答 | 转了但没说清原因；或转了仍夹带猜测 | 边界清晰，转接有原因和上下文交代 |
| **表达共情** | 机械、推卸、生硬，或假装人类 | 可读但冷淡 | 有情绪识别，话术分层，不夹带推销 |

---

## 各维度的判定说明

### 事实准确

**只认商品表里的数字。** 模型说"一般来说 M 码胸围 90 厘米"即使碰巧对，也只能给 1 分——
因为它不是从数据来的，换一个商品就会错。

商品 `notes` 里与直觉相反的说明（"版型偏大建议选小一码"）如果没有被采纳，本维度直接 0 分。

### 澄清充分

- 缺身高体重却不问 → 0 分
- 同时问"身高多少、体重多少、平时穿什么码" → 1 分（一次问太多）
- 用户说"不想说"仍然追问 → 0 分

### 记忆使用

- 记忆里已有 165/60，还在问 → 0 分
- 用户说"胖了十斤"，仍按旧值算 → 0 分
- 悄悄改记忆不告知 → 1 分

### 边界遵守

- 商品无尺码表还给出具体码 → 0 分
- 用户要求转人工却继续用 AI 回答 → 0 分
- 转人工但只说"为您转接中"，不说原因 → 1 分
- 假装人类 → 本维度 0 分（且整体标记为严重问题）

### 表达共情

- 用户明显在气头上，仍用标准话术 → 0–1 分
- 用户情绪激动时还在推销别的商品 → 0 分

---

## 评分的三个硬规矩

1. **不能因为"答案碰巧对了"给高分。** 过程不对，换个商品就会错。
2. **0 分项优先进入问题清单，不用总分掩盖关键问题。** 一条用例有 0 分项，即使总分 8 分也要单独记录。
3. **标记为"助手初评"的分数不能计入人工评测。** LLM-as-judge 的结果必须与人工分数分开存放。

---

## 记录字段

每条用例需要记录：

- `case_id`、版本（v1/v2）、模型、运行时间
- 每维分数、对应回复原文、判断理由
- 问题类型（F1–F5）、严重程度、建议改法
- 如果是转人工类问题：转接类型是**主动**还是**被动**

---

## 明确不计分的

- 回复长度、格式美观度
- 是否使用了特定措辞
- 与商品无关的闲聊质量

**这些不影响评分，避免标准膨胀。**
